# Caderneto Rattenna App 📚

Aplicativo completo de anotações e organização pessoal estilo estante de cadernos.

## Recursos
- 📖 Estante de cadernos personalizada
- 📁 Pastas e subpastas ilimitadas
- 📝 Editor completo de notas com formatação, voz, imagem e tabelas
- 🗓️ Calendário global atualizado (Brasília / DF e fusos horários do mundo)
- 🔒 Fechadura com senha e sincronização via Google/Gmail
- 🎨 Personalização de capas, títulos, ordenação e modo claro/escuro
